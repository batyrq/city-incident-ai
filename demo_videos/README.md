# Demo videos

Six short clips for uploading into the **Try it live** section (`make run`, http://localhost:8000). All are free Mixkit videos (Mixkit Stock Video Free License (https://mixkit.co/license/#videoFree)), not time-lapses (see the check below), trimmed to at most 20 s, 720p H.264, no audio.
Pick one from the dropdown in the live demo (it also sets the recommended pose switch), or upload the file from this folder.

## Notes

- Results are produced by `python scripts/demo_videos_report.py` (default config `configs/infer_pretrained_yolo11s.yaml`, device auto, so MPS with `yolo11s.pt` on this Mac); FPS is end-to-end pipeline FPS of that run and varies with the machine and with pose on/off. The raw numbers are in `reports/metrics/demo_videos.json`.
- Time-lapse check (it rules out time-lapses, not slow motion): mean absolute frame-to-frame change (0-255 grey levels, first 400 frames): a 3.71, b 0.92, c 1.17, d 4.46, e 3.1, f 6.57. For reference, the time-lapse rejected earlier (`data/videos/mixkit-4251.mp4`) scores 8.09 on the same measure.
- Rule thresholds were not changed for any clip (`configs/infer_pretrained_yolo11s.yaml`: `stopped_vehicle` needs 15 s without motion, `crowding` needs 12 people).
- Mixkit's licence allows free commercial and non-commercial use without attribution; the source page of each clip is linked above.
